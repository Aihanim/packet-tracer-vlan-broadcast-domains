# Packet Tracer VLAN Broadcast Domains

## About the Work

The laboratory work was completed in Cisco Packet Tracer.

The work studied VLANs, broadcast domains, collision domains, and ICMP message transmission between computers.

## What Was Done

* checked the connection between PC0 and PC7
* switched to Simulation mode
* configured the ICMP filter
* studied the transmission of broadcast messages
* studied VLAN 10
* studied VLAN 20
* studied VLAN 30
* studied frame transmission between different VLANs
* studied unicast messages
* studied collision domains
* studied broadcast domains

## Technologies Used

* Cisco Packet Tracer
* VLAN
* ICMP
* Ethernet
* Simulation Mode

## Result

As a result of the work, VLAN network segmentation and its effect on broadcast domains were studied.

It was also determined that each switch port is a separate collision domain, while each VLAN is a separate broadcast domain.
